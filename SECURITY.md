# Security policy

Do not include live credentials, tokens, private source code, personal data or exploit details for products you are not authorised to test in public issues.

For vulnerabilities in this repository's scripts, open a minimal issue without sensitive details or use GitHub's private vulnerability reporting if enabled.

This repository does not operate any product with digital elements and is not itself subject to the Cyber Resilience Act's reporting obligations; nothing here should be sent to the ENISA single reporting platform.
